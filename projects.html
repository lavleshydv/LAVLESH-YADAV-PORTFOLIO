Autonomous Carbon-Aware Manufacturing Genome System (ACMGS)

AI-Powered Industrial Process Intelligence & Anomaly Detection

Developed a comprehensive AI-powered manufacturing monitoring and anomaly detection system. The system leverages a Knowledge Graph architecture to analyze industrial batch telemetry, detect process deviations in real-time, and provide automated carbon-efficiency recommendations. Built robust asynchronous REST APIs using FastAPI for seamless visualization and high-throughput ingestion.

Key Engineering Highlights

  • Real-time industrial manufacturing telemetry monitoring pipeline
  • Knowledge Graph-based semantic anomaly detection engine

  • High-speed async endpoints with PostgreSQL persistence

Deep Hybrid Human Activity Recognition (HAR)

Spatial-Temporal Sensor Intelligence with CNN & LSTM

Engineered a deep neural network architecture designed to classify complex human movements and physical activities from multi-axial accelerometer and gyroscope time-series streams. Utilizes 1D Convolutional layers for localized feature extraction coupled with Long Short-Term Memory (LSTM) cells for temporal sequence modeling.

Key Engineering Highlights

  • Hybrid CNN-LSTM network achieving superior classification accuracy
  • Automated noise filtering and sliding-window segmentation pipeline
  • Robust generalization across multi-subject movement datasets
  • Exported optimized inference model for edge mobile/embedded deployment
